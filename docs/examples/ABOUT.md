# Examples

Each subfolder is one worked example: the exact configurations that were run,
generated with the [config builder](https://gcampobello.github.io/ICARUS-LEO/config_builder.html)
and not edited by hand, together with the interactive session viewer produced by
those runs. The configuration is what a user prepares and sends; the viewer is
part of what they receive back, as described in the
[user guide](https://github.com/gcampobello/ICARUS-LEO/blob/main/docs/ICARUS-LEO-UserGuide.md).

Each example reproduces a result reported in the accompanying paper, so the
figures shown in the viewer can be checked against the paper itself.

| Example | What it shows | Viewer |
|---|---|---|
| [`ex_cs1`](ex_cs1/) | Case Study 1: four caching strategies on a dynamic constellation with a lossy channel, seed 1. A single configuration with a parametric sweep | [open](https://gcampobello.github.io/ICARUS-LEO/examples/ex_cs1/viewer.html) |
| [`ex_cs2`](ex_cs2/) | Case Study 2: a real burst-loss trace against a Bernoulli model at matched mean loss, LCD without retransmissions, seed 1 | [open](https://gcampobello.github.io/ICARUS-LEO/examples/ex_cs2/viewer.html) |
